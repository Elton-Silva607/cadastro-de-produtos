# Cadastro de Produtos

Mini projeto de Java - Quality Assurance. Valida nome, preço e quantidade e calcula o valor do estoque.

No IntelliJ, abra o projeto, marque `src` como pasta de código-fonte se necessário e execute `test.ProdutoTest01`. O exemplo cadastra Teclado e Mouse, testa valores inválidos e adiciona três unidades ao estoque.
